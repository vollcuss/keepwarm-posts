# keepwarm-posts

Очередь постов для Instagram @keepwarmkits. Сервер (igpost.py, экземпляр keepwarm) забирает новые папки отсюда и публикует.

## Формат

```
posts/
  YYYY-MM-DD-slug/      # одна папка = один пост; дата = день публикации (не раньше)
    1.jpg ... N.jpg     # карусель 2–10 слайдов, JPEG, 1080x1350
    caption.txt         # подпись с хэштегами
```

Папка, которая уже опубликована, повторно не публикуется (сервер помнит это в своём state-файле).
